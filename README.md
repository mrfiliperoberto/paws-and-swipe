# Paws & Swipe

Paws & Swipe is a pet adoption platform designed to connect verified shelters and rescue organizations with people looking to adopt.

The platform provides pet discovery, adoption applications, shelter management, and communication throughout the adoption process.

## Project Status

🚧 Under active development.

The project is currently in the product definition and architecture phase.

- Mobile application
- REST API
