# Product Requirements

## Product

Paws & Swipe

## Overview

Paws & Swipe is a pet adoption platform that connects verified shelters and rescue organizations with prospective adopters.

The platform aims to make pet discovery easier while providing shelters with tools to manage pets, adoption applications, and communication with prospective adopters.

## User Roles

### Adopter

An adopter can:

- create and manage a profile;
- configure adoption preferences;
- discover available pets;
- filter pets;
- view pet profiles;
- favorite pets;
- submit adoption applications;
- track application status;
- communicate with shelters.

### Shelter Member

A shelter member can:

- create a shelter account;
- submit shelter information for verification;
- manage the shelter profile;
- create and manage pet profiles;
- receive adoption applications;
- review prospective adopters;
- communicate with applicants;
- update application statuses;
- mark pets as adopted.

### Administrator

An administrator can:

- manage users;
- verify shelters;
- moderate pet listings;
- review reports;
- moderate the platform.

## Core Adoption Flow

Discover → Pet Profile → Favorite / Interest → Adoption Application → Shelter Review → Conversation → Meeting → Approval → Adoption
